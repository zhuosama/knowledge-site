PyTorch 常用模型架构地图

PyTorch 常用模型架构地图

Section titled “PyTorch 常用模型架构地图”

摘要

Section titled “摘要”

模型架构不是版本排行，而是对数据结构的假设（归纳偏置）。本页覆盖菜鸟教程目录中的主要模型族，帮助你判断何时使用 Linear、CNN、RNN、Transformer、Autoencoder 或 GAN，并指出它们如何与 YOLO 相连。

1. 快速选型

Section titled “1. 快速选型”
数据/任务首选起点原因
表格特征、基础回归Linear / MLP参数少、基线清晰
图像分类、局部纹理CNN局部连接、权重共享、平移等变性
目标检测CNN/视觉骨干 + 多尺度检测头同时建模语义与空间位置
短/中序列、流式状态GRU/LSTM显式递归状态，逐步处理
长序列、并行训练TransformerSelf-Attention 建模远程依赖
表示压缩、异常检测Autoencoder学习重构和潜在表示
生成图像/域转换GAN（或现代扩散模型）对抗训练学习生成分布

真实项目先建立简单基线，再根据误差和资源约束升级；架构越复杂不等于业务表现越好。^[inferred]

2. 线性回归与 MLP

Section titled “2. 线性回归与 MLP”

线性回归：

y^=XW+b\hat y = XW+by^​=XW+b

MLP 叠加 Linear 与非线性激活，可拟合复杂关系，但对图像空间结构和序列顺序没有专门假设。

4. RNN、LSTM 与 GRU

Section titled “4. RNN、LSTM 与 GRU”

普通 RNN 用前一时刻隐状态处理当前输入：

ht=f(Wxxt+Whht−1+b)h_t=f(W_xx_t+W_hh_{t-1}+b)ht​=f(Wx​xt​+Wh​ht−1​+b)

长序列中容易出现梯度消失/爆炸。LSTM 通过输入、遗忘、输出门控制记忆；GRU 用更少门结构，参数通常更少。

流式推理、传感器时序或小规模序列任务仍可优先考虑 GRU/LSTM；大规模长序列通常会比较 Transformer。

6. Transformer

Section titled “6. Transformer”

Transformer 用多头注意力、前馈网络、残差连接和 LayerNorm 组成 block，可并行处理序列。它没有递归结构，因此必须注入位置/顺序信息。

文本情感分析的一条典型链是 Tokenize → Vocabulary → Embedding → Encoder → Pooling → Linear。torchtext 可辅助文本数据处理，但其版本兼容性应按当前项目核对，不把旧教程中的 API 当作稳定接口。

7. Autoencoder

Section titled “7. Autoencoder”

Autoencoder 由编码器 z=f(x)z=f(x)z=f(x) 与解码器 x^=g(z)\hat x=g(z)x^=g(z) 组成，最小化重构损失。用途包括降维、去噪、预训练和异常检测。

异常检测不能只假设“重构误差高就是异常”；若模型也能很好重构异常，阈值会失效，必须用独立异常数据验证。^[inferred]

10. 架构比较时记录什么

Section titled “10. 架构比较时记录什么”
  • 参数量、FLOPs 只是静态近似；还要测目标硬件延迟和内存。
  • 固定数据划分、输入尺寸、batch、精度和后端。
  • 同时报准确率/损失与任务指标、稳定性和失败样本。
  • 迁移学习、预训练数据和增强策略必须写入实验记录。
