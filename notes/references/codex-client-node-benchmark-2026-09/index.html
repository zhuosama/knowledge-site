判定标准

Section titled “判定标准”

探测端点 https://chatgpt.com/backend-api/me，用 curl.exe（非 PowerShell）：

返回含义
401通路正常，未被挑战 → Codex 可用
403（Cf-Mitigated: challenge）被 Cloudflare 挑战 → Codex 会失败
000 / 超时节点不通

每节点采样 3 次，另测 auth.openai.com/（正常应为 302）。

推荐 🇭🇰 香港A10

Section titled “推荐 🇭🇰 香港A10”

结论：当前选 🇭🇰 香港A10 | IEPL。 理由：唯一同时满足「延迟最低梯队（0.67 s）」+「chatgpt 与 auth 两端点 3/3 全部未被挑战」。 备选 🇸🇬 新加坡A01 | IEPL | x2（0.83 s）。
