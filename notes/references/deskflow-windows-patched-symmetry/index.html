Deskflow Windows 补丁版对称部署

Deskflow Windows 补丁版对称部署

Section titled “Deskflow Windows 补丁版对称部署”

本页记录 2026-06-15 将 Windows Deskflow 端从官方 v1.26.0 升级到与 Mac 端一致的补丁版 v1.26.0.9999 的完整操作实录。核心挑战：Windows 端无 C++ 构建工具链。

问题

Section titled “问题”

本机（Windows，键鼠服务端）跑官方 Deskflow v1.26.0，Mac 端跑 codex 自编译的补丁版 v1.26.0.9999。两端版本不对称的本质是 Mac 的稳定性补丁尚未进到 Windows 跑的二进制里——而 Windows 没有任何 C++ 构建工具链。

技术背景

Section titled “技术背景”

补丁源是私有 fork zhuosama/deskflow-codex-patched（扁平快照，基于上游 commit 1922f916，无 git 历史）。对 Windows 有效的补丁三处：

补丁文件作用
重连风暴保护ClientApp阶梯退避 1/5/15/60/300s + 30 次熔断 + 稳定 5 分钟重置
布局切换守卫KeyMap键盘布局切换时的状态保护
语言码修复win32/AppUtilWindows.cppWindows 键盘语言码处理

macOS 专属补丁（OSXScreen Ctrl-click、TCC/签名）不适用。

操作步骤

Section titled “操作步骤”

1. 比对与确认

Section titled “1. 比对与确认”

比对 fork 与本机基线，确认差异与 Windows 适用补丁，排除 macOS-only 补丁。

2. 创建 CI 构建工作流

Section titled “2. 创建 CI 构建工作流”

往 fork master 添加 .github/workflows/windows-patched-build.yml：

  • 触发器：workflow_dispatch（手动触发）
  • Runner：windows-2022
  • 复用 install-dependencies / get-version 复合 action
  • 绕开 REUSE/clang fail-fast 闸门、去掉 warning-as-error

3. 触发构建 → 下载产物

Section titled “3. 触发构建 → 下载产物”

GitHub Actions run #27575351302，耗时 23 分 44 秒，成功产出补丁版 deskflow-core.exe。

4. 部署

Section titled “4. 部署”

5. 验证

Section titled “5. 验证”
  • 版本对齐：Mac v1.26.0.9999 = Windows v1.26.0.9999 (e905fcce)
  • TCP SynSent+TimeWait 仅 13，无端口耗尽风暴
  • 遗留一步需手动：GUI 重启后不自动拉起 core，需点一次 Start

证据来源

Section titled “证据来源”
  • 项目文档：zhuosama/deskflow-codex-patched:docs/codex-local-patches.md
  • 构建结果：GitHub Actions run #27575351302（success, 23m44s）
  • 版本校验：deskflow-core.exe --version = v1.26.0.9999 (e905fcce)

风险与注意事项

Section titled “风险与注意事项”
  • Qt ABI 兼容性：只换 exe 有 Qt 6.10.2 ABI 不匹配风险；采用整套覆盖策略
  • CI 分钟数限制：私有仓 Windows Actions 分钟有限（2×），适合一次性构建
  • fork CI 冲突：常规 continuous-integration.yml 因新增文件缺 SPDX 头 fail-fast，不影响专用构建流
