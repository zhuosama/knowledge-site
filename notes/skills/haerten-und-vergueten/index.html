Härten und Vergüten von Stahl — 实验流程与结果

来源：TH Nürnberg GSO, Werkstofftechnik BMF 3, Vorlesungsfolien (WiSe 20/21) zur Anwendung von Zustandsdiagrammen und Martensitbildung.

强化机制概述

Section titled “强化机制概述”

材料强度的提升主要基于阻碍位错（Versetzung）运动的原理。不同的障碍物对应不同的强化机制。

障碍物强化机制类型
位错自身Kaltverfestigung（冷变形强化）
晶界（Korngrenzen）Feinkornverfestigung（细晶强化）
溶质原子（gelöste Fremdatome）Mischkristallverfestigung（固溶强化）
第二相粒子（Teilchen）Ausscheidungsverfestigung（沉淀强化）可剪切
第二相粒子（Teilchen）Dispersionsverfestigung（弥散强化）不可剪切

沉淀硬化详解

Section titled “沉淀硬化详解”

基本原理

Section titled “基本原理”

沉淀硬化（Ausscheidungshärten）利用合金元素在固溶体中溶解度随温度降低而减小的特性。工艺通常包括三步：

  1. 固溶处理（Lösungsglühen）：在高温下使合金元素完全溶入基体，形成过饱和固溶体（übersättigter Mischkristall）。
  2. 淬火（Abschrecken）：快速冷却至室温，抑制平衡相析出，保留过饱和状态和高空位浓度。
  3. 时效（Auslagern）：在较低温度下保温，促使细小的第二相粒子弥散析出。

强化机制：剪切与绕过

Section titled “强化机制：剪切与绕过”

位错与析出相粒子的相互作用主要有两种机制：

  • 剪切机制（Schneiden）：适用于尺寸较小（通常 < dkritd_{krit}dkrit​）、与基体共格或半共格的粒子。位错切过粒子，产生新的界面（Kelly-Fine机制），并引起晶格畸变。强化效果随粒子尺寸 dTd_TdT​ 和体积分数 fvf_vfv​ 增大而增强。 Δσ∼dT\Delta\sigma \sim d_TΔσ∼dT​
  • 绕过机制（Umgehen）：适用于尺寸较大、与基体非共格的粒子。位错以Orowan机制绕过粒子，并留下位错环，阻碍后续位错运动。强化效果随粒子间距 LTL_TLT​ 或尺寸 dTd_TdT​ 增大而减弱。 Δσ∼1/LT或1/dT\Delta\sigma \sim 1/L_T \quad \text{或} \quad 1/d_TΔσ∼1/LT​或1/dT​
  • 临界转变：当粒子尺寸达到临界值 dkritd_{krit}dkrit​ 时，两种机制所需的应力相等，强化效果达到峰值。dkritd_{krit}dkrit​ 的范围从硬质非共格粒子的约 3 nm 到较软共格粒子的约 100 nm。

Al-Cu合金的沉淀序列（以Al-4%Cu为例）

Section titled “Al-Cu合金的沉淀序列（以Al-4%Cu为例）”

时效过程中析出相的演化序列及特征如下：

阶段析出相特征尺寸（典型值）与基体关系对硬度的影响
1. 低温时效GP-I区Cu原子团簇，引起晶格畸变直径 ~10 nm，厚度 ~0.2 nm完全共格上升
2. 较高温度时效GP-II区 (θ”)更大的盘状富Cu区直径 10-150 nm，厚度 1-10 nm共格继续上升
3. 更高温度时效Θ’相 (metastabil)化学计量为Al₂Cu的亚稳相直径 0.5-1 µm，厚度 3-10 nm半共格达到峰值
4. 过时效Θ相 (stabil)稳定的Al₂Cu相，粗化直径 0.1-3 µm非共格下降（过时效）

时效动力学：时效温度和时间共同决定析出阶段和最终强度。存在一个最佳时效窗口，温度过高或时间过长会导致粒子粗化（Ostwald-Reifung），强度下降。

纯铁的同素异构转变

Section titled “纯铁的同素异构转变”

纯铁在固态下存在三种同素异构体：

  • δ-Ferrit（δ铁素体）：高于1392°C，体心立方（krz）。
  • Austenit（奥氏体，γ-Eisen）：911°C至1392°C，面心立方（kfz）。
  • Ferrit（铁素体，α-Eisen）：低于911°C，体心立方（krz）。

碳在铁中的溶解度

Section titled “碳在铁中的溶解度”

奥氏体（kfz）和铁素体（krz）的晶体结构差异导致碳溶解度（Löslichkeit）显著不同：

  • 奥氏体 (γ-Fe)：面心立方，间隙尺寸较大（z=0.11z = 0.11z=0.11 nm），最大碳溶解度为 2.06%（在1147°C）。
  • 铁素体 (α-Fe)：体心立方，间隙尺寸较小（z=0.04z = 0.04z=0.04 nm），最大碳溶解度仅为 0.02%。

Fe-Fe₃C相图关键点与反应

Section titled “Fe-Fe₃C相图关键点与反应”

该相图描述亚稳态系统（Eisen-Zementit）。

  • 共晶反应（Eutektikum, I）：在1147°C，含4.3%C的液相（L）转变为奥氏体（γ）和渗碳体（Fe₃C）的混合物（莱氏体）。
  • 共析反应（Eutektoid, II）：在723°C（A₁线），含0.8%C的奥氏体（γ）转变为铁素体（α）和渗碳体（Fe₃C）的层片状混合物——珠光体（Perlit）。 γ0.8%C→723∘Cα+Fe3C(珠光体)\gamma_{0.8\%C} \xrightarrow{723^\circ C} \alpha + Fe_3C \quad (\text{珠光体})γ0.8%C​723∘C​α+Fe3​C(珠光体)

典型合金的冷却转变

Section titled “典型合金的冷却转变”
  1. 共析钢 (0.8% C)：冷却时，在723°C发生共析转变，室温组织为100%珠光体。
  2. 亚共析钢 (如0.6% C)：
    • 冷却至A₃线（~760°C）时，开始从奥氏体中析出先共析铁素体（α）。
    • 冷却至723°C时，剩余奥氏体发生共析转变。
    • 室温组织：铁素体 + 珠光体（比例约为25% : 75%）。
  3. 过共析钢 (如1.2% C)：
    • 冷却至Acm线（~900°C）时，开始从奥氏体中析出先共析渗碳体（Fe₃C，二次渗碳体）。
    • 冷却至723°C时，剩余奥氏体发生共析转变。
    • 室温组织：珠光体 + 渗碳体（比例约为93% : 7%）。先共析渗碳体通常沿原奥氏体晶界呈网状分布。

马氏体相变 (Martensitbildung)

Section titled “马氏体相变 (Martensitbildung)”

基本原理与形成条件

Section titled “基本原理与形成条件”

马氏体相变是一种无扩散、切变型的固-固相变。当奥氏体以超过临界冷却速度（vkritv_{krit}vkrit​）快速冷却时，碳原子来不及扩散析出，发生无扩散的马氏体相变。其特点包括：

  • 非扩散控制：相变过程不依赖于原子的长程扩散（Platzwechsel）。
  • 非平衡条件：需要达到或超过临界冷却速度 vkritv_{krit}vkrit​。
  • 原子移动距离小：原子位移不超过一个原子间距，通过集体、协同的切变（Umklappprozess）完成。

晶格重构与碳的强制固溶

Section titled “晶格重构与碳的强制固溶”
  1. 晶格重构：面心立方（kfz）的奥氏体通过切变转变为体心正方（tetragonal-raumzentriert）的马氏体晶格。
  2. 碳的强制固溶：碳原子被“冻结”在晶格间隙中，导致晶格发生正方畸变（一个轴被拉长，cM>aαc_M > a_\alphacM​>aα​，aM<aαa_M < a_\alphaaM​<aα​）。
  3. 高硬度来源：这种强制固溶引起的巨大晶格畸变和内应力，以及马氏体内部的高密度位错/孪晶，是马氏体具有极高硬度的根本原因。

形貌与影响因素

Section titled “形貌与影响因素”
  • 形貌分类：
    • 板条马氏体 (Lattenmartensit)：常见于低碳钢。
    • 片状马氏体 (Plattenmartensit)：常见于高碳钢。
  • 碳含量的影响：随着碳含量的增加，马氏体的正方畸变程度和硬度均显著提高，同时马氏体开始转变温度 (MsM_sMs​) 和结束温度 (MfM_fMf​) 降低。
  • 冷却速度的影响：转变程度（马氏体含量）是过冷度 (ΔT\Delta TΔT) 的函数。冷却速度必须大于临界冷却速度 vkritv_{krit}vkrit​，以抑制扩散型相变（如珠光体、贝氏体）。

实验：钢的淬火与回火 (Härten und Vergüten)

Section titled “实验：钢的淬火与回火 (Härten und Vergüten)”

实验目标与材料

Section titled “实验目标与材料”

研究C45钢在奥氏体化 (Austenitisieren)、淬火 (Abschrecken) 和回火 (Anlassen) 过程中，硬度与组织的变化规律。

  • 材料：C45E钢 (1.1191)，试样为直径20mm、厚8mm的圆柱体。

实验流程与结果

Section titled “实验流程与结果”
  1. 奥氏体化：在850°C保温，使组织完全转变为奥氏体。
  2. 淬火：将试样投入水中快速冷却。对比了摇动冷却（均匀冷却）和静止冷却（不均匀冷却）两种方式。
    • 结果：淬火后硬度显著提高。摇动冷却的试样硬度更高且更均匀（≥60 HRC），因为冷却更均匀，马氏体转变更完全。静止冷却的试样，与容器底部接触的一侧冷却较慢，硬度较低（≈57 HRC），表明该侧马氏体转变不完全。
  3. 回火：将淬火后的试样在600°C进行不同时间的回火处理。
    • 结果：硬度随时间呈对数下降（例如，2分钟下降约5 HRC，8分钟下降约15 HRC）。回火过程使淬火马氏体中的碳以细小碳化物的形式析出，形成回火马氏体或索氏体（Sorbit），从而降低内应力、减少脆性、提高韧性。
  4. 金相组织观察：
    • 原始态：铁素体 + 珠光体（Perlit）组织。
    • 淬火态：典型的针状马氏体，可能伴有少量残余奥氏体。
    • 回火态：马氏体形态逐渐消失，转变为回火索氏体（铁素体基体上分布着极细的碳化物）。

讨论与结论

Section titled “讨论与结论”
  • 淬火是获得高硬度的关键，其本质是马氏体相变。冷却均匀性对最终硬度有决定性影响。
  • 回火是调整淬火钢性能的必要步骤，通过控制回火温度和时间，可以在降低硬度的同时，大幅提升韧性，从而获得所需的硬度-韧性平衡。
  • 实验中观察到的淬火裂纹，是由于马氏体相变时体积膨胀、表面与芯部温差大以及马氏体本身脆性高共同导致的。

关键考点

Section titled “关键考点”
  1. 强化机制对比：能够区分并解释固溶强化、细晶强化、沉淀强化（剪切与绕过机制）的基本原理。
  2. 沉淀硬化工艺：掌握固溶处理、淬火、时效三步法的目的和原理。
  3. Al-Cu时效序列：了解GP区 → Θ’相 → Θ相的演化过程及其对力学性能的影响。
  4. Fe-C相图核心：
    • 记忆关键温度（A₁: 723°C, A₃: 911°C, 共晶: 1147°C）和成分（共析点: 0.8% C）。
    • 理解奥氏体与铁素体碳溶解度差异的原因（晶格类型与间隙尺寸）。
    • 能够分析亚共析钢和过共析钢在缓慢冷却时的室温组织组成。
  5. 马氏体相变的本质与特征：
    • 本质：无扩散、切变型固态相变，形成过饱和碳的体心正方固溶体。
    • 高硬度来源：碳的强制固溶导致的晶格畸变（正方度）和高位错密度。
    • 形成条件：快速冷却（v>vkritv > v_{krit}v>vkrit​），以抑制扩散型相变。
    • 性能：高硬度、高强度、高脆性。
  6. 淬火与回火工艺：
    • 淬火关键：奥氏体化温度、保温时间、冷却介质与方式（均匀性）。
    • 回火目的：消除内应力、降低脆性、析出碳化物、调整力学性能（硬度-韧性平衡）。
  7. ZTU图（等温转变图）的应用：用于确定获得马氏体所需的冷却条件，区分扩散型与非扩散型相变。
  8. 实验现象解释：能解释摇动与静止淬火的硬度差异、回火硬度下降曲线、以及淬火裂纹的成因。
