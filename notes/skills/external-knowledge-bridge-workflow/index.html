外部知识桥接工作流

外部知识桥接工作流

Section titled “外部知识桥接工作流”

从 3Blue1Brown → SYT Obsidian 桥接项目中提炼的可复用模式。适用于将高质量外部学习资源接入已有知识图谱。

问题场景

Section titled “问题场景”

高质量的外部学习材料（如 3Blue1Brown、MIT OCW、教科书补充阅读）容易变成孤立的笔记堆，而不是连接到已有知识图谱的桥梁。用户需要的是：来源可追溯、概念能链接、能在 live vault 里检索和回看 ^[extracted]。

核心工作流（5 步）

Section titled “核心工作流（5 步）”

步骤 1：选题与映射到当前课程需求

Section titled “步骤 1：选题与映射到当前课程需求”

不是所有外部内容都值得接入 ^[extracted]。先与当前课程需求做映射，只选直接相关的部分。

筛选标准 ^[inferred]：

  • 是否直接支持某项课程概念的直觉理解？
  • 是否会连接到已有知识页面（而非独立存在）？
  • 优先级：服务考试备考 > 课程拓展 > 纯兴趣

步骤 2：原始捕获 — 保存 Source Pack 和 Raw Q&A

Section titled “步骤 2：原始捕获 — 保存 Source Pack 和 Raw Q&A”

在产生任何派生内容之前，先保存原始来源 ^[extracted]：

使用 NotebookLM 对选定的来源生成 Q&A 原始输出，保存为 .raw.json 或 .raw.md 文件。这些是可信来源链——即使后续派生内容有误，也可以回溯检查。

⚠️ NotebookLM 答案是有用的综合辅助，但仍然是从上传来源派生的。对数学公式、数值结论和考试关键判断仍需要回查原始课程资料。

步骤 3：写桥接页（references/），而非孤立摘要

Section titled “步骤 3：写桥接页（references/），而非孤立摘要”

在 references/ 目录下创建桥接页面，而非在 concepts/ 下直接创建新概念：

  • 桥接页定位为「外部视角解释器」^[inferred]
  • 文件名：<source>-<topic>-bridge.md（如 3blue1brown-syt-fourier-complex-bridge.md）
  • 内容：用外部材料的直觉解释补充课程概念，不替代课程讲义

步骤 4：连接到已有课程概念

Section titled “步骤 4：连接到已有课程概念”

桥接页通过显式 wikilink 连接到已有课程页面：

同时更新课程概念页的反向链接，让桥接页成为学习路径的一部分。

步骤 5：用真实 Vault 的 Obsidian CLI 和 Link Audit 验证

Section titled “步骤 5：用真实 Vault 的 Obsidian CLI 和 Link Audit 验证”

Agent 完成桥接工作后，必须验证用户的真实 Obsidian vault（而非 agent 自己的 worktree）^[extracted]：

  1. 同步到真实 vault 路径（[private vault path] 上的 live vault）
  2. 使用 Obsidian CLI 检查 backlinks 和 unresolved links
  3. 运行 link audit 验证无断链

报告中分别列出 source artifact（原始捕获）和 derived note（派生笔记），让用户清楚哪些是源、哪些是派生。

详见 Canonical Vault 同步方法。

产出物类型

Section titled “产出物类型”
内容类型放置位置说明
外部来源的原始 Q&Alocal workflow不在 wiki 内，作为 source artifact
桥接页references/外部视角解释器
课程概念concepts/从课程内容派生的知识
来源索引references/<source>-core-index.md如 3B1B SYT Core Index

反模式

Section titled “反模式”
  • ❌ 把全平台内容都接入 → 产生噪音，稀释有效链接
  • ❌ 直接创建独立的概念页而不写桥接页 → 失去追溯链
  • ❌ 在 agent worktree 中完成但不验证真实 vault → 用户看不到产出
  • ❌ 丢弃原始 NotebookLM 输出 → 无法回溯检查派生内容是否准确
  • ❌ 把 source artifact 和 derived note 混为一谈 → 用户无法分辨可信度 ^[inferred]

历史案例：3Blue1Brown → SYT Obsidian 桥接

Section titled “历史案例：3Blue1Brown → SYT Obsidian 桥接”

这是本工作流的首个实践案例（2026-06-15）^[extracted]：

  • 从 3Blue1Brown 174 个 lesson 中选出 5 个 SYT-relevant core lessons
  • 创建 Laplace bridge note，连接 SYT Laplace、DGL、Fourier、Zustandsraum 和高频考点页面
  • 使用 NotebookLM 导入 10 个 URL 和 source pack，保存 raw Q&A JSON
  • 验证：用 Obsidian CLI + link audit 确认 live vault 中无断链

该次实践证明了：外部课程资料可以先保留 raw source artifact，再产出 derived note，最后在 live vault 中验收——这一模式可复用于任何高质量公开视频课或 course website。
