交互式可视化学习实验设计

交互式可视化学习实验设计

Section titled “交互式可视化学习实验设计”

此方法论提炼自 SYT 7 模块交互可视化实验室的设计与实施（SYT 可视化实验室 · 未公开）。

适用场景

Section titled “适用场景”

当一门工程/数学课程满足以下条件时，交互可视化实验可以显著提升理解效率：

  • 核心概念涉及参数变化 → 行为变化的动态关系（卷积、频域、极点、采样）
  • 静态公式和图表难以传达”如果参数改变会怎样”的直觉
  • 外部视频（如 3Blue1Brown）提供了好的视觉隐喻，但没有映射到课程的具体公式和符号

七步设计流程

Section titled “七步设计流程”

1. 课程事实定界

Section titled “1. 课程事实定界”

从课程笔记、formelsammlung、考试要求中提取：

  • 哪些概念最需要直观理解（典型标志：学生能套公式但画不出图）
  • 课程的公式符号、坐标系约定和术语（不能直接搬运外部视频的符号）
  • 哪些概念在考试中是”画图题”或”定性判断题”

2. 外部视觉隐喻调研

Section titled “2. 外部视觉隐喻调研”

搜索 3Blue1Brown、GitHub 可视化项目等外部资源：

  • 提取可复用的视觉表达（Fourier winding、卷积滑动窗口、pole-zero plot）
  • 不搬运公式——只借鉴”怎么画”而不是”画什么数值”

3. 少量高频模块 MVP

Section titled “3. 少量高频模块 MVP”

从 3-5 个最高频的理解难点开始，每个模块满足：

  • 单屏幕可见（不滚动即可看到核心控件）
  • 参数调节后即时反馈（<100ms 视觉更新）
  • 与课程的至少一个 Hilfsmittel 位置对应

4. Bounded Implementation Delegation

Section titled “4. Bounded Implementation Delegation”

将 MVP 交给 bounded subagent 实施：

  • 技术选型：standalone HTML（Canvas API / vanilla JS），零依赖、零构建链
  • 指定每个模块的输入参数范围、输出视觉类型、坐标轴标签
  • 不交由 subagent 决定数学公式——主 agent 应先确认公式正确性

5. 主代理验收

Section titled “5. 主代理验收”

验收分为三层，分开跑：

层检查内容
数学验证用已知参数组合测试输出值是否与手算一致
交互验证CDP 驱动真实控件状态，检查所有 slider/button 的取值边界
视觉验证桌面和移动端截图，检查安全区、颜色对比度、坐标轴可读性

6. Deep-Link 回接学习入口

Section titled “6. Deep-Link 回接学习入口”

在所有学习入口中增加模块直达链接：

  • Formal wiki 概念页（每个相关概念页至少一个链接）
  • 课程 staging 笔记（每个章节至少一个链接）
  • Hilfsmittel / formelsammlung（对应公式旁边加链接）
  • High-yield 复习笔记
  • 课程 README 和 learning guide

使用 hash deep links（如 #faltung、#pole）实现模块级直达。

7. Live-Vault 验证

Section titled “7. Live-Vault 验证”
  • 修改 wiki 页后不只用 obsidian reload——必须 kill 进程重启（metadata cache 不重读 frontmatter）
  • 用 link audit 检查所有新增链接可解析
  • 跨至少两个设备验证（桌面 + 移动端）

技术约束

Section titled “技术约束”
  • 单文件 standalone HTML：Canvas API + vanilla JS，浏览器即运行
  • 零依赖：不引入 npm/CDN 依赖链
  • 移动端兼容：responsive layout, touch-friendly slider

实践经验

Section titled “实践经验”

来自 SYT 可视化实验室的关键教训（详情 · 未公开）：

  • 发现并修正了 signed alias phase、卷积空交集、移动端 tab 换行和直接 hash 定位问题
  • 7 个模块覆盖了从卷积到 z 域的主要理解链，但 Ch6 理想系统尚未覆盖
  • 54 个回链入口分布在 22 份文档中，确保实验室不是孤立 demo 而是学习图谱的一部分
