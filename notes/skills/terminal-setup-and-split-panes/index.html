终端环境配置与分屏操作

终端环境配置与分屏操作

Section titled “终端环境配置与分屏操作”

本页记录本机终端环境的搭建结果，并重点给出怎么分屏（同时多终端工作）的快捷键速查。

环境总览

Section titled “环境总览”
层组件说明
终端模拟器Windows Terminal已装，默认 profile = PowerShell 7
Windows 侧 shellPowerShell 7.6.4D:\apps\PowerShell\7.6.4
Linux 侧 shellWSL2 Ubuntu 22.04wsl 进入，默认用户 root
提示符starshipWindows 与 WSL 共用同一主题
目录跳转zoxide两侧都已配置并预置数据库
终端工具fzf / ripgrep / lazygit / eza / bat / tmux装在 WSL

分屏有两层，先选对工具

Section titled “分屏有两层，先选对工具”
  • Windows Terminal 窗格/标签 → 开多个独立 shell（每个窗格可以是不同 profile：PowerShell、WSL、cmd）。日常多开首选。
  • tmux → 在一个 WSL 会话内部再分屏，而且会话可持久化（断开/关窗后 tmux attach 能接回），适合跑长任务、防掉线。

一、Windows Terminal 分屏（最常用）

Section titled “一、Windows Terminal 分屏（最常用）”
操作快捷键
新建标签页Ctrl+Shift+T
拆分窗格（复制当前 profile）Alt+Shift+D
上下分屏Alt+Shift+-
左右分屏Alt+Shift+=
在窗格间移动焦点Alt+方向键
关闭当前窗格Ctrl+Shift+W
切换标签Ctrl+Tab / Ctrl+Shift+Tab
命令面板（搜所有动作）Ctrl+Shift+P

鼠标也可：按住 Alt 点窗格切换焦点；右键标签栏可新建标签 / 拆分窗格。

想在 WSL 上分屏：Alt+Shift+D 复制的是当前窗格。当前若是 PowerShell，复制出来的还是 PowerShell；要开 WSL，点标签栏下拉箭头选 Ubuntu-22.04，再对它 Alt+Shift+D。

二、tmux 分屏（WSL 内部，可持久化）

Section titled “二、tmux 分屏（WSL 内部，可持久化）”

启动：在 WSL 里敲 tmux。所有 tmux 命令都先按前缀键 Ctrl+b（按下松开），再按功能键。

操作按键
左右分屏Ctrl+b 然后 |（或 %）
上下分屏Ctrl+b 然后 -（或 "）
切换窗格Ctrl+b 然后方向键；或直接鼠标点（已开 mouse）
直接切窗格（免前缀）Ctrl+h / Ctrl+j / Ctrl+k / Ctrl+l
关闭当前窗格Ctrl+b 然后 x
新建窗口Ctrl+b 然后 c
切换窗口Ctrl+b 然后 n / p，或数字键
脱离（后台继续跑）Ctrl+b 然后 d
重新接回tmux attach
列出会话tmux ls

本机 ~/.tmux.conf 已配置：鼠标支持、窗口从 1 编号、| / - 分屏、Ctrl+h/j/k/l 直接切窗格。

五、常见问题

Section titled “五、常见问题”
  • z wiki 没反应 — vault 根目录叫 Onedrive 不叫 wiki，zoxide 按目录名匹配。跳 vault 用 wiki 函数或 z Onedrive。
  • 改了 .bashrc 不生效 — 新开标签页即可（Ctrl+Shift+T）。
  • 星舰/PowerShell 提示 “预测建议无法启用” — 只在非交互或重定向输出时出现，真实交互终端不受影响。
  • 刚装的命令行工具找不到 — winget 改过 PATH，需要新的 shell 会话才会读到。
