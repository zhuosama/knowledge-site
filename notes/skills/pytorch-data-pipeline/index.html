PyTorch 数据管道

PyTorch 数据管道

Section titled “PyTorch 数据管道”

摘要

Section titled “摘要”

Dataset 定义“第 i 个样本是什么”，DataLoader 定义“如何批量、洗牌、并行地取样本”，Transform 定义“样本如何转换”。数据管道不仅影响速度，也直接决定验证可信度和模型能学到什么。

1. Dataset 与 DataLoader 的职责

Section titled “1. Dataset 与 DataLoader 的职责”

Map-style Dataset 至少实现 __len__ 和 __getitem__；流式或无限数据可实现 IterableDataset。

2. 最小自定义 Dataset

Section titled “2. 最小自定义 Dataset”

__getitem__ 不应悄悄吞掉坏样本；数据损坏应在预检查阶段显式报告，否则训练样本数和类别分布会悄然改变。^[inferred]

3. Transform

Section titled “3. Transform”

当前 torchvision 教程使用 torchvision.transforms.v2：

训练集可使用随机增强；验证/测试集应使用确定性预处理。预训练模型通常要求特定 resize 和 normalization，应以权重对象提供的 transforms 为准。

4. 创建 DataLoader

Section titled “4. 创建 DataLoader”
参数作用常见建议
batch_size每批样本数受显存、统计稳定性和吞吐约束
shuffle每 epoch 重排索引train 通常 True，val/test False
num_workers子进程加载数从 0 开始验证，再逐步增加并测吞吐
pin_memory使用锁页 CPU 内存CUDA 训练常设 True，并配合非阻塞拷贝
drop_last丢弃最后不完整 batchBatchNorm 或固定 batch 场景按需使用
collate_fn把样本组成 batch可变长度文本、检测框等任务需要自定义

Windows 脚本应把启动代码放在 if __name__ == "__main__": 下；多进程异常时先用 num_workers=0 分离问题。

5. 把 batch 移到设备

Section titled “5. 把 batch 移到设备”

不要在 Dataset.__getitem__ 中把每个样本直接放进 CUDA；多 worker、显存管理和复用会变得困难。通常在训练循环的 batch 边界统一迁移。

6. 数据划分与泄漏

Section titled “6. 数据划分与泄漏”
  • 随机划分只适合近似独立同分布样本。
  • 视频相邻帧、同一患者、同一零件、同一人的多张图应按 group 划分。
  • normalization 的统计量只能由训练集估计。
  • 测试集用于最终确认，不应反复参与调参。
  • 固定划分清单与随机种子，比只写 80/20 更可复现。

7. 类别不平衡与采样

Section titled “7. 类别不平衡与采样”

先统计每类样本数和实际业务频率。可以使用 WeightedRandomSampler、损失权重或补采数据，但采样后的训练分布会影响概率校准。验证集应尽量反映真实场景，而不是跟着训练采样策略改变。^[inferred]
