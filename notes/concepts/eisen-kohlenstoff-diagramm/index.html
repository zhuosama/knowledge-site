Eisen-Kohlenstoff-Diagramm

来源：TH Nürnberg GSO, Werkstofftechnik BMF 3, PPT 09 “Anwendung Zustandsdiagramme” (WiSe 20/21)

纯铁的同素异构转变

Section titled “纯铁的同素异构转变”

纯铁在固态下随温度变化会发生晶体结构转变，称为同素异构转变（Allotropie）。

  • δ-Ferrit（δ-铁素体）：在 1536°C（熔点）至 1392°C 之间存在，为体心立方（krz）结构。
  • Austenit（奥氏体） 或 γ-Eisen（γ-铁）：在 1392°C 至 911°C 之间存在，为面心立方（kfz）结构。
  • Ferrit（铁素体） 或 α-Eisen（α-铁）：在 911°C 以下存在，为体心立方（krz）结构。

Eisen-Kohlenstoff-Diagramm（铁碳相图）概述

Section titled “Eisen-Kohlenstoff-Diagramm（铁碳相图）概述”

铁碳相图描述了铁（Fe）与碳（C）组成的合金系统中，相、组织与温度、成分之间的关系。工程上主要研究亚稳的 Fe-Fe₃C（铁-渗碳体）系统。

  • 亚稳系统（Metastabiles System）：Eisen – Zementit (Fe₃C)（铁-渗碳体）。
  • 稳定系统（Stabiles System）：Eisen – Grafit (C)（铁-石墨），在常规冷却速率下难以达到。

碳在铁中的溶解度

Section titled “碳在铁中的溶解度”

碳原子（直径0.15 nm）以间隙形式存在于铁的晶格中。由于奥氏体（kfz）的间隙尺寸（0.11 nm）大于铁素体（krz）的间隙尺寸（0.04 nm），因此奥氏体能溶解更多的碳。

  • Austenit（奥氏体，γ-Fe）：最大溶解度为 2.06% C（在1147°C），晶格常数 aγ=0.36a_\gamma = 0.36aγ​=0.36 nm。
  • Ferrit（铁素体，α-Fe）：最大溶解度仅为 0.02% C（在723°C）^[inferred]^，晶格常数 aα=0.29a_\alpha = 0.29aα​=0.29 nm。

关键点与相区

Section titled “关键点与相区”

铁碳相图中包含几个重要的恒温转变点和相区边界线。

关键恒温转变

Section titled “关键恒温转变”
名称温度反应含碳量产物
共晶转变（Eutektikum）1147°CL → γ + Fe₃C4.3% CLedeburit（莱氏体）
共析转变（Eutektoid）723°Cγ → α + Fe₃C0.8% CPerlit（珠光体）

重要相区边界线

Section titled “重要相区边界线”
  • A₃ 线（GS线）：奥氏体中开始析出铁素体（α）的温度线。
  • Acm 线（ES线）：奥氏体中开始析出二次渗碳体（Fe₃C_II）的温度线。
  • A₁ 线（PSK线）：共析转变温度线（723°C）。

共析转变与珠光体（Perlit）

Section titled “共析转变与珠光体（Perlit）”

在 723°C（A₁温度），含碳量为 0.8% 的奥氏体发生共析分解： γ(0.8%C)→723∘Cα(0.02%C)+Fe3C(6.67%C)\gamma (0.8\% C) \xrightarrow{723^\circ C} \alpha (0.02\% C) + Fe_3C (6.67\% C)γ(0.8%C)723∘C​α(0.02%C)+Fe3​C(6.67%C) 产物为 珠光体（Perlit），它是铁素体（α）和渗碳体（Fe₃C）交替排列的层片状机械混合物。珠光体的形成是一个扩散控制的过程，碳原子在奥氏体中进行长程扩散，形成富碳的渗碳体层和贫碳的铁素体层。扩散距离 xxx 与扩散系数 DDD 和时间 ttt 的关系为： x=D⋅tx = \sqrt{D \cdot t}x=D⋅t​

亚共析钢（Untereutektoider Stahl）的冷却转变

Section titled “亚共析钢（Untereutektoider Stahl）的冷却转变”

以含碳量 0.6% C 的合金为例（低于0.8%）。

  1. 高温：完全为 Austenit（奥氏体）。
  2. 冷却至A₃线（GS线）以下：开始从奥氏体中析出先共析 Ferrit（铁素体）。
  3. 冷却至A₁线（PSK线，723°C）：剩余的奥氏体（此时含碳量已增至0.8%）发生共析转变，转变为 珠光体。
  4. 室温组织：由 铁素体 和 珠光体 组成。根据杠杆定律计算，0.6% C钢的室温组织约为 75% 珠光体 和 25% 铁素体。

[Fragment unklar: 源文本中出现的 α → α + Tertiärzementit 可能指在极低碳含量（<0.015% C）下，铁素体冷却时析出三次渗碳体的过程，但此片段信息不完整。]

过共析钢（Übereutektoider Stahl）的冷却转变

Section titled “过共析钢（Übereutektoider Stahl）的冷却转变”

以含碳量 1.2% C 的合金为例（高于0.8%）。

  1. 高温：完全为 Austenit（奥氏体）。
  2. 冷却至Acm线（ES线）以下：开始从奥氏体晶界析出先共析 二次渗碳体（Sekundärzementit, Fe₃C_II）。
  3. 冷却至A₁线（PSK线，723°C）：剩余的奥氏体（此时含碳量降至0.8%）发生共析转变，转变为 珠光体。
  4. 室温组织：由 珠光体 和 网状二次渗碳体 组成。根据杠杆定律计算，1.2% C钢的室温组织约为 93% 珠光体 和 7% 渗碳体。

关键考点

Section titled “关键考点”
  1. 纯铁的三个同素异构体及其存在温度范围和晶体结构（krz/kfz）。
  2. 铁碳相图的两个系统：亚稳的Fe-Fe₃C系统和稳定的Fe-C（石墨）系统。
  3. 碳在奥氏体和铁素体中溶解度差异的原因（晶格间隙大小）及具体数值（2.06% vs 0.02%）。
  4. 共晶转变（1147°C, 4.3%C） 和 共析转变（723°C, 0.8%C） 的反应式、产物及名称（莱氏体、珠光体）。
  5. A₃、Acm、A₁线的物理意义。
  6. 亚共析钢和过共析钢从奥氏体区冷却至室温的组织演变过程，以及室温组织的组成（铁素体+珠光体 vs 珠光体+渗碳体）。
  7. 珠光体的本质（铁素体与渗碳体的层片状混合物）及其形成机制（扩散控制的共析分解）。
  8. 能在Fe-Fe₃C相图中准确识别γ相区、α+γ两相区、珠光体转变线（PSK）及共析点（S点）。
