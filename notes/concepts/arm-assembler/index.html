ARM Cortex-M 汇编编程

ARM Cortex-M 汇编编程

Section titled “ARM Cortex-M 汇编编程”

基于 TH Nürnberg MCT 课程第 3 章：ARM 处理器与汇编语言

寄存器模型

Section titled “寄存器模型”

ARM Cortex-M4 使用 16 个 32-bit 通用寄存器（R0–R15）加上特殊功能寄存器：

通用寄存器

Section titled “通用寄存器”
寄存器用途
R0–R3工作寄存器（Low），函数调用时用于参数传递
R4–R7工作寄存器（Low），编译器用于存储内部变量
R8–R12高端寄存器（High），编译器用于存储变量
R13栈指针 SP（MSP = Main Stack Pointer，PSP = Process Stack Pointer）
R14链接寄存器 LR（Link Register），存储函数返回地址
R15程序计数器 PC（Program Counter）

R0–R3 在函数调用时由编译器自动用于参数传递，编写 Stack Frame 时需特别注意。^[inferred]

特殊功能寄存器

Section titled “特殊功能寄存器”
寄存器功能
xPSR组合程序状态寄存器（Combined PSR）
APSR应用程序状态寄存器 — NZCV 标志位
IPSR中断状态寄存器 — 当前 ISR 编号
EPSR执行状态寄存器 — Thumb 状态位
PRIMASK中断屏蔽寄存器（除 NMI 和 Fault 外）
FAULTMASK中断屏蔽寄存器（除 NMI 外）
BASEPRI优先级选择的中断屏蔽寄存器
CONTROL状态控制（User/Supervisor 模式、SP 选择）

UAL 汇编语法

Section titled “UAL 汇编语法”

ARM 使用 UAL（Unified Assembler Language） 统一 ARM 和 Thumb 指令集语法。

指令格式

Section titled “指令格式”
  • Op — 操作码（Opcode）
  • cond — 条件码（可选，条件执行）
  • type — 数据宽度（H = Halfword，B = Byte，默认 = Word）
  • Rd — 目标寄存器
  • Rm, Rn — 源操作数寄存器

UAL 有 3 个操作数：目标 + 两个来源。^[extracted]

伪汇编指令

Section titled “伪汇编指令”
指令功能示例
.equ定义常量.equ GPIOA_MODER, 0x40020000
.section定义内存段.section .vectortable
.align N内存对齐（2^N 字节）.align 2 = Word 对齐
.word存储一个 Word.word 0x12345678
.hword存储一个 Halfword.hword 0x4321
.byte存储一个 Byte.byte 0x3F
.ascii存储字符串（含 0 终止）.ascii "Hello\n"

指令集分类

Section titled “指令集分类”

Cortex-M0 到 M4 的指令集向上兼容（ARMv6-M → ARMv7-M）：

指令组功能
Load/Store内存与寄存器之间的数据传输
Branch程序跳转与条件分支
Data-processing算术与逻辑运算
Status register access状态寄存器读写
Miscellaneous其他（如 NOP、IT 等）

Load/Store 架构

Section titled “Load/Store 架构”

ARM 是典型的 Load/Store 架构：

  • 数据必须先从内存 加载 到寄存器（LDR）
  • 运算只在寄存器之间进行
  • 结果通过 存储 写回内存（STR）

条件执行与分支

Section titled “条件执行与分支”

条件码

Section titled “条件码”

ARM 支持条件执行，基于 APSR 中的 NZCV 标志位：

后缀含义条件
EQEqualZ=1
NENot EqualZ=0
GTGreater ThanZ=0 且 N=V
LTLess ThanN≠V

分支指令

Section titled “分支指令”

BL 指令将下一条指令地址存入 R14（LR），实现函数调用的返回机制。^[extracted]

处理器模型（单周期）

Section titled “处理器模型（单周期）”

ARM 单周期处理器的模块化设计包括：

  1. 指令取指单元（Instruction Fetch Unit）
  2. 译码器/控制器（Decoder/Control Unit）
  3. 寄存器组（Register File）
  4. 算术逻辑单元（ALU）
  5. 总线接口（Bus Interface）

该模型参考 Harris & Harris 的 “Digital Design and Computer Architecture, ARM Edition”，以及 TU Darmstadt 的 ARMv7-Logisim 项目。^[extracted]
