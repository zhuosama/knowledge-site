焊接接头（熔焊/压焊）Schweissverbindungen

Section titled “焊接接头（熔焊/压焊）Schweissverbindungen”

来源：TH Nürnberg Konstruktion 2 课件 K2_06

定义

Section titled “定义”

焊接（Schweißen）是材料连接（stoffschlüssig）、不可拆卸的连接方式。

  • 母材处于液态或塑性状态
  • 使用热量和/或力
  • 可使用或不使用附加材料

→ 与 焊接接头（钎焊）Lötverbindungen 的区别：焊接温度高于母材熔点

Section titled “压焊方法详解”
方法原理
点焊（Punktschweißen）电极加压 + 电流
缝焊（Rollen-/Nahtschweißen）滚轮电极连续焊接
凸焊（Buckelschweißen）预制凸点集中加热

超声焊（Ultraschallschweißen）超声振动 + 压力

熔焊适用材料

Section titled “熔焊适用材料”
  • 结构钢：低碳钢好焊，高碳钢需预热和焊后退火
  • 调质钢：需预热
  • 渗碳钢：渗碳前焊接（合金渗碳钢需预热）
  • 不锈钢：除高 C 和 S 钢外可焊
  • 铸铁：灰口铸铁 GGL、球墨铸铁 GGG
  • 轻金属：Al、Al 合金、Mg 合金（优选 WIG、MIG）
  • 重金属：Cu、CuSn、CuZn（Zn 含量低时好焊）

焊缝截面选择（V-Naht 等）

Section titled “焊缝截面选择（V-Naht 等）”

取决于板厚 s：

  • s = 2~4 mm：I 缝或卷边缝
  • s ≤ 1.5 mm：卷边缝
  • s = 4~15 mm：V 缝
  • s = 10~30 mm：X 缝
  • s > 30 mm：U 缝

Section titled “名义应力”
载荷公式
拉/压σ_{z,d} = F / A_Schw ≤ σ_{zul}
剪切τ_a = F / A_Schw ≤ τ_{zul}
扭转τ_t = M_d / W_{tSchw} ≤ τ_{zul}
弯曲σ_b = M_b / W_{bSchw} ≤ σ_{zul}
