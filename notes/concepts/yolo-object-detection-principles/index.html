YOLO 目标检测原理

YOLO 目标检测原理

Section titled “YOLO 目标检测原理”

摘要

Section titled “摘要”

本文面向第一次接触目标检测的学习者。目标是让你能解释 YOLO 为什么快、模型输出代表什么、训练损失如何推动模型学习，并能区分经典 YOLOv1 与 YOLOv8 等现代实现。

[!summary] 一句话理解 YOLO 把“图中有什么、在哪里”一次性变成一个密集预测问题：整张图只经过一次主干网络，模型便同时给出候选框、类别和可信程度。

1. 目标检测在解决什么问题

Section titled “1. 目标检测在解决什么问题”

图像分类只回答“图里主要是什么”；目标检测还要回答“每个目标在哪里”。每个检测结果通常包含：

例如一张街景可能输出 person 0.91、car 0.87 和各自的矩形框。检测器既要识别类别，又要完成空间定位。

2. YOLO 与 Faster R-CNN 的本质区别

Section titled “2. YOLO 与 Faster R-CNN 的本质区别”
维度YOLO（典型单阶段）Faster R-CNN（两阶段）
第一步在整幅特征图上直接产生密集预测RPN 先提出可能有目标的候选区域
第二步没有独立的候选框分类阶段对候选区域做 RoI 特征提取，再分类和回归
计算特点大量计算共享，一次前向传播得到结果候选区域还需进一步处理
常见优势延迟低、吞吐高、部署链短小目标、遮挡或高精度任务上常有很强基线
常见代价极端小目标、密集遮挡更依赖尺度与训练设计推理更慢、系统更复杂

“You Only Look Once”不是说网络只有一层，而是说检测不需要先裁候选区域再逐个识别。现代单阶段和两阶段方法已经互相吸收许多技术，不能简单断言某一类永远更准。^[inferred]

3. 通用网络结构：Backbone、Neck、Head

Section titled “3. 通用网络结构：Backbone、Neck、Head”
  • Backbone：逐级下采样并提取特征。浅层分辨率高，适合定位小结构；深层语义强，适合区分类别。
  • Neck：常用 FPN/PAN 类多尺度融合，让检测头同时看到细节与语义。
  • Head：在多个尺度的特征图上预测边界框和类别。现代 YOLO 常采用分类与回归分支分开的 decoupled head（解耦头）。
  • 后处理：传统版本通过 NMS（非极大值抑制）删除大量重叠框；YOLOv10 等端到端设计可实现 NMS-free。

YOLOv8 使用改进的 CSP 风格主干/Neck、C2f 模块和 anchor-free split head；不同 YOLO 分支的具体模块并不相同。

4. 网格划分：经典说法与现代说法

Section titled “4. 网格划分：经典说法与现代说法”

4.1 YOLOv1 的 S×S 网格

Section titled “4.1 YOLOv1 的 S×S 网格”

YOLOv1 将输入划分为 S×SS\times SS×S 个网格。如果一个物体的中心落在某个网格，该网格负责预测它。每个网格预测 BBB 个框和 CCC 个类别概率，经典输出张量可写为：

S×S×(B⋅5+C)S\times S\times(B\cdot 5+C)S×S×(B⋅5+C)

每个框的 5 个量是 (x,y,w,h,confidence)(x,y,w,h,\text{confidence})(x,y,w,h,confidence)。这种“一格负责中心落入其中的目标”的解释非常适合入门，但不要机械套到所有现代版本。

4.2 现代 YOLO 的多尺度密集预测

Section titled “4.2 现代 YOLO 的多尺度密集预测”

现代 YOLO 通常在多个分辨率的特征图上预测。例如输入为 640×640640\times640640×640 时，检测层可能对应步长 8、16、32。小步长特征图保留更多空间细节，大步长特征图具有更大的感受野。YOLOv8 是 anchor-free：不再为每个位置预先规定若干固定形状的 anchor，而是直接学习目标边界到参考点的距离分布。

[!warning] 常见误解 “YOLO 一定把图片切成 7×7 小块”“每格只能预测一个物体”“所有 YOLO 都要调 anchor”只准确描述某些早期版本，不是现代 YOLO 的通用事实。

5. 边界框、置信度与类别概率

Section titled “5. 边界框、置信度与类别概率”

5.1 边界框表示

Section titled “5.1 边界框表示”

标注和网络内部常见两种表示：

  • xyxy：左上角 (x1,y1)(x_1,y_1)(x1​,y1​)、右下角 (x2,y2)(x_2,y_2)(x2​,y2​)。
  • xywh：中心 (xc,yc)(x_c,y_c)(xc​,yc​)、宽 www、高 hhh；YOLO 数据集文本使用归一化 xywh。

5.2 IoU

Section titled “5.2 IoU”

交并比衡量预测框与真实框重叠程度：

IoU=∣Bpred∩Bgt∣∣Bpred∪Bgt∣IoU=\frac{|B_{pred}\cap B_{gt}|}{|B_{pred}\cup B_{gt}|}IoU=∣Bpred​∪Bgt​∣∣Bpred​∩Bgt​∣​

IoU 为 1 表示完全重合，为 0 表示不相交。GIoU、DIoU、CIoU 等变体会额外考虑外接框、中心距离或宽高比，使框不重叠时也能提供更有用的梯度。

5.3 Objectness、类别概率与最终分数

Section titled “5.3 Objectness、类别概率与最终分数”

早期/部分 YOLO 中可以用下面的直觉理解：

score(class)≈P(object)×P(class∣object)\text{score(class)}\approx P(\text{object})\times P(\text{class}\mid\text{object})score(class)≈P(object)×P(class∣object)

即“这里确实有物体”的可信程度乘以“物体属于某类别”的条件概率。不同版本的头部和标签分配方式不同；YOLOv8 检测损失的日志通常显示 box_loss、cls_loss、dfl_loss，不要强行寻找一个独立的 v1 式 objectness 输出。

5.4 NMS

Section titled “5.4 NMS”

同一物体往往产生多个重叠候选框。NMS 的做法是保留最高分框，并删除与它 IoU 过高的同类框。conf 太低会产生许多误检，太高会漏检；iou 阈值决定重叠框合并的激进程度。

6. 损失函数：模型从哪里知道自己错了

Section titled “6. 损失函数：模型从哪里知道自己错了”

训练目标可概念化为：

L=λboxLbox+λobjLobj+λclsLclsL=\lambda_{box}L_{box}+\lambda_{obj}L_{obj}+\lambda_{cls}L_{cls}L=λbox​Lbox​+λobj​Lobj​+λcls​Lcls​

6.1 定位损失

Section titled “6.1 定位损失”

让预测框靠近真实框。YOLOv1 对坐标使用平方误差，并对宽高取平方根以减弱大框误差的支配；现代实现更多使用 IoU 系列损失。YOLOv8 还使用 **DFL（Distribution Focal Loss）**学习边界距离的离散概率分布，使回归不只输出一个生硬数值。

6.2 置信度或目标性损失

Section titled “6.2 置信度或目标性损失”

让目标位置得高分、背景位置得低分。由于背景远多于目标，如果权重不平衡，模型可能学会“到处都是背景”。早期 YOLOv1 用 noobj 权重降低大量背景格子的影响；现代方法通过标签分配、BCE/Focal 类损失及采样策略处理不平衡。

6.3 分类损失

Section titled “6.3 分类损失”

让正样本位置预测正确类别。多标签式检测头常使用 BCE；类别极不平衡时可考虑 Focal Loss 或重新采样，但应先确认标注和验证集没有问题。

6.4 YOLOv8 日志中的三项

Section titled “6.4 YOLOv8 日志中的三项”
日志项作用异常信号
box_loss框的位置、大小和重叠质量长期高且 mAP 不升：框标注、尺度或数据可能有问题
cls_loss类别判别类 ID 错位、长尾类别或相似类别容易使其偏高
dfl_loss边界距离分布回归小目标、模糊边界或错误框会增加难度

损失值用于优化，同一实现内可看趋势；不同版本、模型尺寸和超参数的绝对值通常不能直接横比。

7. 从预测到评估

Section titled “7. 从预测到评估”
  • Precision：预测为目标的结果中，有多少是真的；误检少则高。
  • Recall：真实目标中，有多少被找到；漏检少则高。
  • AP50：IoU=0.50 条件下各置信度阈值的平均精度。
  • mAP50-95：在 IoU 0.50–0.95 多个阈值上平均，更严格，更适合比较模型。
  • 混淆矩阵：看哪些类别相互混淆以及背景误检/漏检。

实际系统还必须测目标硬件上的延迟、吞吐、显存/内存、功耗和端到端预处理时间；论文 FPS 不能直接替代部署实测。^[inferred]
