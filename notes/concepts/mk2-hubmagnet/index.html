MK2 Tutorium – Hubmagnet 吸持电磁铁

Hubmagnet 吸持电磁铁(SoSe20 A2,27 P —— 全卷最高分题)

Section titled “Hubmagnet 吸持电磁铁(SoSe20 A2,27 P —— 全卷最高分题)”

1. Funktionsprinzip(功能原理)

Section titled “1. Funktionsprinzip(功能原理)”

Anker(衔铁)被吸向使磁路磁阻(Reluktanz)最小的位置 —— 磁力永远试图把气隙”关掉”。官方答案原话:“Anker bewegt sich, um mag. Widerstand (Reluktanz) zu minimieren.”

!mk2-hubmagnet-typen.png · 未公开

Umkehrhubmagnet(左)与 Doppelhubmagnet(右)的简化剖面:两个 Joch + 一个 Anker。

2. UHM vs DHM(SoSe20 A2a,7 P)

Section titled “2. UHM vs DHM(SoSe20 A2a,7 P)”
Umkehrhubmagnet (UHM)Doppelhubmagnet (DHM)
Ankerlang(长,贯穿磁轭)kurz(短)
复位/方向双向磁吸力mech. Rückstellung(弹簧复位);只有从中位出发有磁作用
Hub较小、吸力大相对大的行程

共同点:Zwei Joche, ein Anker(两个轭 + 一个衔铁)。

3. 磁路链与力-行程特性

Section titled “3. 磁路链与力-行程特性”

Θ=N⋅I  ⇒  ϕ=ΘRm  ⇒  Rm≈δμ0A  (气隙主导)  ⇒  F∝(N⋅Iδ)2\Theta = N\cdot I \;\Rightarrow\; \phi = \frac{\Theta}{R_m} \;\Rightarrow\; R_m \approx \frac{\delta}{\mu_0 A}\;(\text{气隙主导}) \;\Rightarrow\; F \propto \left(\frac{N\cdot I}{\delta}\right)^2Θ=N⋅I⇒ϕ=Rm​Θ​⇒Rm​≈μ0​Aδ​(气隙主导)⇒F∝(δN⋅I​)2

铁芯 μr 很大 → 磁阻几乎全在气隙 δ 上 → δ 越小吸力平方级上升 → Kraft-Hub-Kennlinie 呈双曲线形。^[inferred]

4. Einschaltprozess 吸合过程(A2b,5 P)

Section titled “4. Einschaltprozess 吸合过程(A2b,5 P)”

!mk2-hubmagnet-einschalt.png · 未公开

上:DC 吸合过程的 u(t)、i(t)、s(t);下:AC 下 F∝i² 的脉动与嗡鸣。

  • u(t):合上开关即跳变为 U。
  • i(t) 不是单调指数上升,这是本题的 Besonderheit:初始 δ 大 → L 小 → τ = L/R 小 → 电流快速上升;当 i 足够大使 F > Feder + Last(t1)后 Anker 开始运动 → 气隙闭合 → L 增大,dL/dt > 0 产生 Gegen-EMK → 电流出现明显下凹(Dip);t2 到位后运动停止,电流才以大的 τ 继续升到终值 I∞ = U/R。^[inferred]
  • 该定性曲线对 Hubmagnet 和 Relais(继电器)都成立。

5. Ansprechzeit 吸合时间(A2c,3 P)

Section titled “5. Ansprechzeit 吸合时间(A2c,3 P)”

定义:从接通电压到 Anker 到达终端位置的时间(t2)。

影响因素:电气时间常数 τ = L/R(电流上升快慢)、使 Anker 启动所需的电流水平(由 Feder/Last 决定)、运动质量。官方答案关键词:Skizze, Funktion, L/R。

6. AC-Brummen 与 Verklemmen(A2d,4 P)

Section titled “6. AC-Brummen 与 Verklemmen(A2d,4 P)”
  • 嗡鸣:F ∝ i²。交流 i 每个周期两次过零 → 力每个周期两次归零 → 带机械负载的 Anker 每次过零被负载拉回、下一半波又猛地吸合撞击 Ankergegenstück → 撞击噪声频率 f = 2f₀(50 Hz 电网 → 100 Hz)。
  • Verklemmen(意外卡死在中间位置):气隙保持很大 → R_m 大 → L 小 → 交流下 I ≈ U/(ωL) 持续很大 → 线圈过热烧毁。
  • 对比:DC 电磁铁电流只由 R 限制(I = U/R),卡死不额外增大电流;Verklemmen 主要是 AC 问题。^[inferred]

7. Kennlinie 造型与 F–I 关系(A2e/A2f,3+5 P)

Section titled “7. Kennlinie 造型与 F–I 关系(A2e/A2f,3+5 P)”
  • Kraft-Hub-Kennlinie 的形状由 Anker 和 Ankergegenstück 的几何形状决定(平面极面 → 力大行程短;锥形等造型 → 曲线更平、行程更长)。
  • F 与 Spulenstrom:I ∝ H,线性段 B ∝ H → F ∝ B² ∝ I²;随后 Eisen 进入 Sättigung(饱和) → F 增长变缓封顶。
  • Ankermaterial 通过 μr 的大小和磁化曲线的饱和形状决定最大吸力。

8. Klausur-Timing

Section titled “8. Klausur-Timing”

SoSe20:45 min / 68 P ≈ 0.66 min/P → A2(27 P)≈ 18 min;子题预算 a≈4.5, b≈3.5, c≈2, d≈2.5, e≈2, f≈3.5 min。^[inferred]
