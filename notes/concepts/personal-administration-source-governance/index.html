个人行政资料来源治理模式

个人行政资料来源治理模式

Section titled “个人行政资料来源治理模式”

一种系统化治理模式，用于应对分散在公开网页、登录系统、共享盘和邮件中的个人行政信息。核心理念：先把边界和失败模式写进系统，再扩大收集范围。

问题特征

Section titled “问题特征”

适用场景通常有以下特征 ^[inferred]：

  • 信息来源分散：同时涉及法规文档、内网门户、邮件、共享盘、同学/同事口头信息
  • 隐私敏感：含个人信息、成绩、邮件原文、登录截图
  • 时效性强：内网页、考试计划等需要定期重核
  • 权威层次复杂：官方法规 > 部门公告 > 教师邮件 > 同学经验

五步实施顺序

Section titled “五步实施顺序”

从 B-MF 本科事务资料库 · 未公开 项目中提炼的可复用步骤 ^[extracted]：

1. 权威注册表（Source Registry）

Section titled “1. 权威注册表（Source Registry）”

建立 sources.yaml 或等效的语义注册表，记录每个来源的 ^[extracted]：

  • authority：官方/半官方/非官方
  • applicability：适用人群、适用 cohort
  • review_policy：复核周期（每学期/每年/事件驱动）
  • category：法规、表格、流程说明、联系信息
  • access_boundary：公开网页/登录态/VPN/邮件/共享盘

2. 私密原始证据层（Private Raw Evidence）

Section titled “2. 私密原始证据层（Private Raw Evidence）”

将含个人信息、邮件、登录截图、已填表格等原始证据放在不进入同步的私密层 ^[extracted]：

  • 位置与公开层物理隔离（不同目录/不同同步策略）
  • 脱敏后才进入公开知识层
  • 私密层内容不跨 Agent 传播原文

3. 脱敏知识页（Sanitized Knowledge Pages）

Section titled “3. 脱敏知识页（Sanitized Knowledge Pages）”

人工复核、脱敏后产出结构化知识页 ^[extracted]：

  • 必须引用 source ID
  • 法规/PDF 给页码
  • 写清适用人群与未确认项
  • 区分：已由官方来源确认 / 由门户动态状态确认 / 合理推断 / 尚未确认

4. 自动生成视图（Auto-Generated Views）

Section titled “4. 自动生成视图（Auto-Generated Views）”

通过脚本从注册表和知识页自动生成 ^[extracted]：

  • Dashboard 入口页
  • 来源展示页（Records）
  • 全文索引

生成产物不承载独有事实——所有事实必须回溯到人工知识页或注册表。^[inferred]

5. 审计与冷备（Audit + Cold Backup）

Section titled “5. 审计与冷备（Audit + Cold Backup）”

每次变更后运行 ^[extracted]：

  • 审计：PII 扫描、断链检测、generated ownership 校验
  • 冷备：日期化增量备份 + 校验（二次执行复制数为 0 证明增量正确）

隐私边界设计原则

Section titled “隐私边界设计原则”
  • 公开层只放脱敏后的结论和引用，不放含个人信息的原文 ^[extracted]
  • 登录态/内网抓取产物先放私密 staging，审核后再迁移脱敏版本 ^[extracted]
  • 自动抓取不能替代正式解释；硬期限和个案决定以负责部门书面答复为准 ^[extracted]
  • 跨 Agent 交接只传：问题、source ID、结论状态、缺口和下一步——不传登录 cookie、截图、邮件正文或学号 ^[extracted]

与 Agent 协作的关系

Section titled “与 Agent 协作的关系”

此模式天然适配多 Agent 环境：不同 Agent（Codex/Claude/Hermes）通过统一的注册表和知识页查询，而不是各自维护分散记忆。详见 Bachelor-BMF 跨 Agent 资料接入契约 · 未公开。^[inferred]

适用范围

Section titled “适用范围”

不仅适用于学籍事务，对以下场景同样适用 ^[inferred]：

  • 个人税务/法律文件管理
  • 多银行/多保险账户资料整理
  • 求职流程中的公司调研与邮件跟踪
  • 任何”分散在多个系统、含隐私信息、需要可追溯权威来源”的个人资料场景
